# Support / Unterstützung

Stand 22.11.2026 · Glide 1.0.1

## English

Installation and usage support:

1. Read the [project README](README.md), the [English user guide](01_Repository/Glide/docs/user-guide/README.md) and its [troubleshooting page](01_Repository/Glide/docs/user-guide/12-troubleshooting.md). The authoritative [feature guide (German)](01_Repository/Glide/docs/20_FUNKTIONEN.md) has every detail.
2. Search existing [GitHub issues](https://github.com/n05a-design/glide-to-do/issues).
3. Report defects with the [bug form](.github/ISSUE_TEMPLATE/fehler.yml).
4. Use the dedicated [documentation, localization, and accessibility forms](.github/ISSUE_TEMPLATE/).
5. Never disclose vulnerabilities in public issues; follow [SECURITY.md](SECURITY.md).

Please include synthetic data and reproducible steps only.

## Deutsch

Verwendung, Installation und Fehler:

1. Prüfe die [Projekt-README auf Deutsch](README.de.md) und den [Funktionsumfang (Deutsch)](01_Repository/Glide/docs/20_FUNKTIONEN.md).
2. Suche bestehende [GitHub-Issues](https://github.com/n05a-design/glide-to-do/issues).
3. Verwende für Fehler das [Fehlerformular](.github/ISSUE_TEMPLATE/fehler.yml).
4. Verwende für Dokumentation, Lokalisierung oder Accessibility die entsprechenden [Issue-Formulare](.github/ISSUE_TEMPLATE/).
5. Sicherheitslücken gehören nicht in ein öffentliches Issue; siehe [SECURITY.md](SECURITY.de.md).

Bitte füge nur künstliche Daten und reproduzierbare Schritte hinzu.
