# Archiv – Python-Versionen

Stand 03.11.2026 · Glide 3.50.1 · aktuelle Python-Lieferung 3.50.1

Hier liegen die abgelösten Hauptdateien `Glide-Aufgaben-und-Listen_v<Version>.pyw`: 3.45.0, 3.46.0, 3.47.0, 3.49.0 und 3.50.0. Die gelieferte 3.50.1 liegt eine Ebene höher. Für die nie gelieferte 3.48.0 wird keine Archivdatei erzeugt.

Aufbewahrt werden höchstens die sieben neuesten Projektversionen. Die überalterte 3.44.0 wurde beim Versionswechsel 3.50.1 nach der bestehenden Regel lokal bytegleich gesichert und aus dem aktiven Baum genommen; sämtliche Vorfassungen bleiben über Git abrufbar. `scripts/pflege/ablage_kuerzen.py` prüft die Altersgrenze. Diese README wird als aktuelle Ablageübersicht gepflegt; sie ist kein eingefrorener Altversionsbeleg.

Die aktuelle Lieferdatei gehört eine Ebene höher. Bytegleichheit zur Quelle wird beim tatsächlichen Lieferabschluss hergestellt; ein neuerer Prüfkandidat darf davon getrennt sein. Keine Ordnerkopien ganzer Stände – Vorfassungen der Module trägt Git.

Ältere Fassungen nur mit getrennter Ablage (`GLIDE_DATA_DIR`) starten. Sie brauchen passende Module ihres historischen Standes; die heutigen Module eine Ebene höher sind kein garantierter kompatibler Laufzeitstand. Einen Bestand aus einer neueren Formatstufe nur mit belegtem Altleser-Schreibschutz öffnen.
