# Aktuelle startbare Python-Fassung

Glide 3.8.0 · Entwicklungsstand 12.09.2026 · Aufgabenformat 13 · Vorlagenformat 2

[Glide-Aufgaben-und-Listen_v3.8.0.pyw](Glide-Aufgaben-und-Listen_v3.8.0.pyw)
ist die aktuelle Arbeitskopie des kanonischen Codes. Der vollständige
Nachbarordner `resources` gehört dazu. Am Mac mit Python 3 inklusive Tk starten;
die laufende ältere Instanz vorher schließen.

Neu: Erinnerungen in den Punktdetails, gespeicherter Aufschub und eine gemeinsame
Übersicht. Hinweise erscheinen innerhalb der laufenden App und heben zusätzlich
den Eintrag in Taskleiste bzw. Dock hervor – einmal je Prüflauf, ohne das Fenster
nach vorn zu reißen; abschaltbar in den persönlichen Einstellungen. Bei beendetem
Programm gibt es weiterhin keine Systembenachrichtigung.

Beim ersten Speichern älterer Daten wird die Originaldatei unverändert unter
`backups/liste_vor_format13_<Zeitstempel>.json` gesichert. Version 3.7 kann Format 13
nicht lesen. Der frühere 3.7-Stand bleibt als Vorgänger erhalten und wird nicht
parallel weiterentwickelt. Originaldaten wurden nicht für Tests verwendet.
