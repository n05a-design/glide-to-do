# Kanonischer Source

`app.pyw` ist der getestete, produktive Source-Stand von Glide 3.2.0. Die Anwendung bleibt in dieser Stabilisierung bewusst als Monolith erhalten. Eine spätere Aufteilung in UI, Datenmodell, Persistenz, Pfade und Versionierung benötigt ein eigenes Refactoring mit Regressionstests.

Die Datei ist bytegleich zur jeweils aktuellen Einzeldatei unter `07_Python-Versionen/`.
