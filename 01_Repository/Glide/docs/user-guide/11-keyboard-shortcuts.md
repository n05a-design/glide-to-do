# Keyboard shortcuts – Glide user guide

Status as of 24.11.2026 · Glide 1.0.3 · Task format 26

**Deutsch:** Shortcuts are described in their sections of [`20_FUNKTIONEN.md`](../20_FUNKTIONEN.md), for example [§2 Seitenleiste](../20_FUNKTIONEN.md#2-seitenleiste-und-navigation), [§6 Pinnwand](../20_FUNKTIONEN.md#6-pinnwand), [§9 Pixel-Werkstatt](../20_FUNKTIONEN.md#9-pixel-werkstatt) and [§10 Suche, Aktionen, Erinnerungen](../20_FUNKTIONEN.md#10-suche-aktionen-erinnerungen) · [Guide contents](README.md) · Previous: [Backups](10-backups.md) · Next: [Troubleshooting](12-troubleshooting.md)

> Controlled translation of the German function reference. If the texts differ, the German text applies. Inside Glide, **Help › Show keyboard shortcuts** lists every shortcut by group.

"Ctrl/Cmd" means Ctrl on Windows and Linux and Cmd on macOS. Shortcuts shown with only "Ctrl" use the Control key on every platform. Planning shortcuts do not work while a text editor has focus.

## General

| Shortcut | Action |
|---|---|
| Ctrl/Cmd+O | Search pages, items and actions (command palette); type `>` for actions only |
| Ctrl/Cmd+F | Focus the search field of the current view |
| Ctrl/Cmd+Z | Undo |
| Ctrl/Cmd+Shift+Z, on Windows also Ctrl+Y | Redo |
| Ctrl/Cmd+C / Ctrl/Cmd+V / Ctrl/Cmd+A | Copy, paste, select all items |
| Ctrl/Cmd+S | Save now (in the task inspector: apply changes) |
| Ctrl/Cmd+P | Print and PDF |
| Ctrl/Cmd+E / Ctrl/Cmd+I | Export / import the open list as TXT |
| Ctrl/Cmd+D | Switch between light and dark within the design |
| Ctrl/Cmd+Shift+K | Compact mode on/off |
| Ctrl/Cmd+H | Change history |
| Ctrl+Q | Quit (on macOS use the system's Quit command) |
| F1 | Built-in manual |
| Escape | Close search, pickers and dialogs, from the inside out |

## Creating and editing

| Shortcut | Action |
|---|---|
| Ctrl/Cmd+N | Go to the entry line |
| Ctrl/Cmd+Shift+N | New list |
| Ctrl/Cmd+Alt+N | Quick capture |
| Enter / Shift+Enter (in the entry line) | Create / open the full entry form |
| F2 | Task details (inspector) |
| F3 | Rename the open list, page or folder |
| Ctrl+M | Title and description of the open list or page |
| Ctrl/Cmd+T | Set the due date |
| Ctrl/Cmd+Shift+P | Schedule (set the planned day) |
| Alt+P | Cycle importance |
| Ctrl/Cmd+L | Manage labels |
| Ctrl/Cmd+G | Group the selection |
| Delete (macOS: Backspace) | Move the selected item to the trash, when no text field has focus |
| Ctrl+W | Move the open list to the trash (asks first) |

## Planning and views

| Shortcut | Action |
|---|---|
| Ctrl/Cmd+K | Week/month calendar |
| Ctrl/Cmd+Shift+T | Time block (date and time) |
| Ctrl/Cmd+Shift+F | Start focus for the selected or next task |
| Alt+↑/↓ (in the schedule or grid) | Move a time block by 15 minutes |
| Ctrl/Cmd+Shift+O | Open the task as a tab (up to twelve) |
| Ctrl/Cmd+Shift+W | Close the tab |
| Ctrl+Page Down / Ctrl+Page Up | Next / previous tab |

## Sidebar and lists

| Shortcut | Action |
|---|---|
| Alt+↑/↓ | Move the selected row among its siblings |
| Alt+→ / Alt+← | Move into the folder above / up one level |
| Alt+←/→ (grouped list or board) | Move to the neighboring group and set its field |

## Pages, notes and the side view

| Shortcut | Action |
|---|---|
| / (at the start of a line) | Block picker |
| Ctrl/Cmd+/ | Block actions for the current line |
| @ (at the start of a word) | Link a page, list or task |
| Ctrl/Cmd+click | Open a link target |
| Ctrl/Cmd+Shift+click | Open a link target in the side view |
| Shift+Enter (on a search result) | Open in the side view |
| Ctrl/Cmd+F (in the side view) | Search inside the side view; Enter/Shift+Enter for next/previous hit |
| Alt+←/→ (in the side view) | Back / forward |
| Alt+↑/↓ (in the side view) | Next / previous section |

## Pinboard

| Shortcut | Action |
|---|---|
| Arrow keys, Home/End, Enter | Select cards, open a card |
| Alt+arrow keys | Move the selected card by one grid step |
| Ctrl/Cmd+Enter | New connected card next to the selected one |
| Ctrl/Cmd+click | Add a card to the selection |
| F11 | Full screen |

## Pixel workshop

| Shortcut | Action |
|---|---|
| B, F, I, L, U, E, S | Brush, fill, eyedropper, line, rectangle, ellipse, selection |
| M | Symmetry |
| X / D | Swap / reset foreground and background colors |
| P | Preview at original size |
| Ctrl+mouse wheel | Zoom around the pointer |
| Shift (while drawing) | Keep angles and squares |
