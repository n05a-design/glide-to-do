# Archiv – Python-Versionen

Ablage für überholte Stände **dieses Ordners**. Der jeweils aktuelle Stand
bleibt eine Ebene höher liegen; hier landet, was er ersetzt hat.

## Hierher gehört

Jede Einzeldatei `Glide-Aufgaben-und-Listen_v*.pyw`, die nicht mehr die
aktuelle ist. Stand 01.09.2026 also v2.4.1, v2.5.0, v2.5.1, v2.5.2, v2.5.3,
v2.5.4 und v2.5.5.

## Hierher gehört nicht

Die aktuelle Einzeldatei. Sie muss eine Ebene höher liegen bleiben und
bytegleich zu `01_Repository/Glide/src/glide/app.pyw` sein – die README des
übergeordneten Ordners nennt diese Regel als verbindlich.

## Warum dezentral archiviert wird

Bis 3.1.0 gab es zusätzlich ein zentrales `100_Archiv` für eingefrorene
Gesamtstände. Es wurde aufgelöst: Jeder Ordner archiviert seit 3.2.0 selbst,
was er ersetzt hat. Der Rückgriff auf eine einzelne Vorgängerdatei soll nicht
bedeuten, einen ganzen Altbestand durchsuchen zu müssen – und ein zweiter
Archivbegriff daneben führte regelmäßig zur Frage, welcher der beiden gemeint
ist.

## Pflegeregel

Nichts wird gelöscht, nur verschoben. Die Datei behält ihren Namen samt
Versionsangabe, damit die Reihenfolge ohne Zeitstempel lesbar bleibt.
