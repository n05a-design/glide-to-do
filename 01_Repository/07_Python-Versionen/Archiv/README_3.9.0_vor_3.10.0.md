# Aktuelle startbare Python-Fassung

Glide 3.9.0 · Entwicklungsstand 12.09.2026 · Aufgabenformat 13 · Vorlagenformat 2

[Glide-Aufgaben-und-Listen_v3.9.0.pyw](Glide-Aufgaben-und-Listen_v3.9.0.pyw) ist die aktuelle Arbeitskopie des kanonischen Codes. Der vollständige Nachbarordner `resources` gehört dazu. Am Mac mit Python 3 inklusive Tk starten; eine laufende ältere Instanz vorher schließen.

Neu: einheitliche Benachrichtigungen, kompakte Kopfzeile, Einstellungszahnrad, Light/Dark Mode in den Einstellungen, durchsuchbare App-Aktionen und ausblendbare Seitenleiste. Dropdowns liegen innerhalb des Elternfensters und verwenden keinen eigenen Eingabegriff. Neue Listen/Ordner nutzen die tatsächliche Formularhöhe oder zwei Spalten.

Datenformat und vorhandene Benachrichtigungen bleiben unverändert. Hinweise werden innerhalb der laufenden App verarbeitet, optional mit Hervorhebung in Dock/Taskleiste. Keine Systemzustellung bei beendetem Programm. Tests verwenden ausschließlich isolierte Daten. Der vorherige 3.8-Quellstand bleibt erhalten.
