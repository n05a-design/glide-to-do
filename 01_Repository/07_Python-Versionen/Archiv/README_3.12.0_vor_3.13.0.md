# Aktuelle startbare Python-Fassung

Glide 3.12.0 · Entwicklungsstand 13.09.2026 · Aufgabenformat 13 · Vorlagenformat 2

[Glide-Aufgaben-und-Listen_v3.12.0.pyw](Glide-Aufgaben-und-Listen_v3.12.0.pyw) ist die aktuelle Arbeitskopie des kanonischen Codes. Der vollständige Nachbarordner `resources` gehört dazu. Am Mac mit Python 3 inklusive Tk starten; eine laufende ältere Instanz vorher schließen.

Neu: „Mein Tag“ wählt Aufgaben aus mehreren Listen unabhängig von ihrer Fälligkeit für den aktuellen Tag aus. Schnellerfassung mit deutscher Fristvorschau und gespeicherte Filter ergänzen die Reiter- und Pinnwandansichten. Alle Ansichten bearbeiten dieselben Objekte.

Aufgabenformat 13 bleibt unverändert. Ansichtspositionen liegen in Einstellungen, nicht in Aufgabenbackups. Benachrichtigungen funktionieren innerhalb der laufenden App. Keine Systemzustellung bei beendetem Programm. Vorherige startbare Versionen bleiben erhalten.
