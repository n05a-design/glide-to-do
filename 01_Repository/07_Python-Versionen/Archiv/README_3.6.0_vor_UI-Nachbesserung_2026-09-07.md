# Startbare Python-Version Glide 3.6.0

Aktuelle Kopie: `Glide-Aufgaben-und-Listen_v3.6.0.pyw`.
Sie wird mit dem kanonischen `01_Repository/Glide/src/glide/app.pyw` abgeglichen.
Den danebenliegenden Ordner `resources/fonts` mitführen; er enthält die privat
geladenen TTF-Dateien und Lizenz.

Start mit Python samt Tk, unter Windows beispielsweise durch Zuordnung von
.pyw zu Python. Geprüfte Umgebung: Python 3.12.7 und Tk 8.6.13.
Nutzdaten liegen außerhalb dieses Ordners. Datei → Datenordner zeigt den
tatsächlichen Pfad.

Ältere Versionen bleiben in `Archiv`. Sie nicht parallel auf dieselbe Datenablage
ansetzen. [Aktueller QA-Bericht](../01_Repository/Glide/docs/18_QA_3.6.0.md).
