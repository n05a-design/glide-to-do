# Offene Entscheidungen – Glide 3.24.0

Stand: 19.09.2026 · Glide 3.24.0 · Aufgabenformat 16

Fragen, die nicht im Code beantwortet werden können, weil sie Geschäft, Recht
oder Produktausrichtung betreffen. Die Punkte aus 3.23.0 gelten unverändert
weiter, soweit sie hier nicht als beantwortet genannt sind:
[Offene Entscheidungen 3.23.0](Offene_Entscheidungen_3.23.0.md).

## Mit 3.24.0 beantwortet

| Frage aus 3.23.0 | Antwort |
|---|---|
| **Gerichtete Abhängigkeiten** | Teilweise. Eine Verbindung trägt seit 3.24 eine Richtung und wird als Pfeil gezeichnet. Sie bleibt eine **Darstellung**, keine Aufgabenabhängigkeit: keine Prüfung auf Kreise, keine Wirkung auf Fälligkeit, Sortierung oder Listenansicht. Ob daraus eine echte Abhängigkeit werden soll, bleibt offen. |
| **Bereiche auf der Pinnwand** (Feature-Gap 2.4) | Teilweise. Hierarchie entsteht über drei Kartengrößen und über die globale Fläche. Abgegrenzte, benannte Bereiche mit eigenem Rahmen gibt es nicht. |

## Neu mit 3.24.0

| Frage | Zusammenhang | Wer entscheidet |
|---|---|---|
| **Soll aus der Richtung eine echte Abhängigkeit werden** | Dann braucht es Kreisprüfung, eine Darstellung in Liste und Tabelle und eine Regel, was ein blockierter Punkt in „Mein Tag“ bedeutet. Das ist eine Funktion, keine Linie. | Inhaber |
| **Reisen Pinnwände zwischen zwei Beständen** | Der additive Import übernimmt heute Listen- und Ordnerflächen, die globale bewusst nicht. Wer zwei Geräte zusammenführt, könnte eine Zusammenführung erwarten – das hieße, zwei globale Flächen zu mischen. | Inhaber |
| **Sichtbare Bereiche statt nur Größen** | Benannte Flächenbereiche wären ein zweites Ordnungsmittel neben Listen und Ordnern. Die Produktgrenze „eine Aufgabe, viele Ansichten“ bleibt dabei gewahrt, die Bedienung wird aber deutlich größer. | Inhaber |
| **Wie weit darf der Dopamin-Modus gehen** | 3.24 stapelt fünf Fahnen, lässt Ränder pulsen und zählt Kombos. Ton, Bildschirmblitze oder eine dauerhafte Punktezahl wären der nächste Schritt – und die Grenze zur Gamifizierung, die Glide bisher meidet. | Inhaber |
| **Zählt eine Kombo als Leistungsmessung** | Sie lebt nur in der Sitzung und wird nirgends gespeichert. Sobald sie gespeichert würde, wäre sie eine Bewertung der eigenen Arbeit – genau das, was die Regel „keine Produktivitätsbewertung“ ausschließt. | Inhaber |

## Unverändert offen

Publisher- und Herausgebername, Markenprüfung, Vertriebsweg, Signierung und
Notarisierung, Preisfrage, Name der Markenfigur und die Anbindung an einen
KI-Dienst stehen unverändert in
[Offene Entscheidungen 3.23.0](Offene_Entscheidungen_3.23.0.md).
